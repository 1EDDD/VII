# Devil May Cry 3 Special Edition Arabic Localization

Arabic localization project for the Nintendo Switch version of Devil May Cry 3 Special Edition, intended for use with MeloNX.

## Scope
- Arabic menus and UI
- Tutorials and gameplay prompts
- Items, weapons, styles, mission text and results
- Story dialogue
- Arabic font / RTL support where technically possible
- ROMFS mod packaged for MeloNX Mod Manager

## Important
This repository contains localization work and patches only. It does not contain copyrighted game ROMs or extracted game assets.

## Compatibility
Target: Devil May Cry 3 Special Edition for Nintendo Switch, tested with MeloNX.
